# P5-3：第二轮消融如何改变结论

结果见 [第二轮报告](../../reports/ablation_round2.md)。本节解决的问题是：第一轮看起来好的改动，换成更合适的基线训练规则后是否还好？

## 阅读顺序

先看 `configs/train/p5b/base_seed0.yaml`，明确 batch、warmup 和 tokens；再看 Muon、A7 配置的差异。接着读 `scripts/analyze_p5.py` 的 `read_run` 和 `ablation_report`，理解最后一次评测、基线均值、样本标准差和子集比较。

基线均值 3.3373，Muon 3.3048，差为 -0.0325。第一轮对应差值 -0.0799，所以 Muon 仍有收益，但优势缩小；基线变强会改变对改动价值的判断。

## 验证与自己重建

从每个 JSONL 取出 eval，检查最终 step=3014、tokens=790102016。先写出三个种子的 loss，再使用样本标准差（分母 n-1）。对每个变体减去基线均值，最后逐子集重复。不要把三个种子的 2σ 当作正式显著性检验。

本次已核对五组最终评测、记录步数和总 loss 的七子集均值。可以对照 `reports/ablation_round2_evidence.json` 检查最终原始数值和文件哈希。

## 已验证的错误分析练习

不修改原始数据，只改变分析筛选条件：仅取 step > 200 的训练行，Muon 梯度峰值约 0.78；取全程训练行，step 40 出现 8.35。两种结果本次均已计算验证。这说明“后期平稳”不能被写成“全程没有尖峰”，日志每 20 步采样也不是完整轨迹。

再比较 Muon 和 A7：差仅约 0.0038，小于基线样本标准差约 0.0089；直接宣布 Muon 获胜会夸大证据。补变体种子或组合实验，比继续解读第四位小数更有价值。
