# 技术报告模板

结构照 **OLMo 2** 和 **SmolLM2** 的技术报告。最终产出 `reports/technical-report.md`（或 PDF），配套 W&B 公开 report、HuggingFace 模型卡。

---

## 报告骨架

### 0. 摘要
一段话：训了什么、用了多少算力、达到什么水平、最主要的三个发现。

### 1. 引言与目标
- 为什么做这个（学习目标，不是刷 SOTA）
- 明确的非目标：不追求超越同规模 SOTA，不做 MoE，不做多模态
- 全部产出的清单与开源地址

### 2. 分词器
- 训练语料与规模、算法、词表大小的选择理由
- **fertility 对照表**：中/英/代码/数学，与 Qwen2.5、Llama-3、GPT-4o 对比
- 词表大小对参数量和有效 token 预算的影响分析

### 3. 数据
- **漏斗表**：每个子集的原始 → 语言过滤 → 质量过滤 → 去重 → 去污染后的文档数与 token 数
- 去污染细节：命中哪些评测集、剔除多少
- 最终配比表 + 选择依据（引用 P5 消融结果）
- 退火期数据的构成
- 附录：每子集随机 5 条样本原文

### 4. 模型架构
- 超参表
- **参数量逐项推导表**（见 [02-architecture.md](02-architecture.md)）
- 每个架构选择的理由，以及哪些是照抄惯例、哪些是自己验证过的
- 与 HF Llama 的数值对齐结果

### 5. 训练
- 完整超参表
- LR 日程图
- **loss 曲线**（train/val，分子集）
- **grad_norm 曲线** —— 标出所有 spike 的位置及处置
- **MFU 曲线**与吞吐量，硬件配置
- 总 FLOPs、总耗时、总成本、碳排估算
- 断点续训次数、被抢占次数（真实的工程记录）

### 6. 缩放律
- 4 个规模点的 `L(N)` 拟合，参数 `L∞ / A / α`
- **外推预测的 500M loss vs 实际值** —— 差多少？为什么？
  这是报告里最有研究味的一节。

### 7. 消融实验
一张主表，每行：配置 / val loss / HellaSwag / 训练时间 / **你据此做的决定**。

覆盖：优化器、激活函数、GQA vs MHA、数据配比、LR 日程、稳定性技巧。

### 8. 评测
- 主结果表 + 基线对照（见 [07-evaluation.md](07-evaluation.md)）
- **能力随训练 token 的增长曲线**（中间 checkpoint 评测）
- harness 版本与 few-shot 设置说明
- 定性生成样本对比（附录）

### 9. 后训练
- SFT 数据、chat template、超参
- DPO 的 reward margin 与 KL 曲线
- SFT 前后的人工并排对比结果

### 10. 局限与失败记录
**这一节最有价值，认真写。**
- 模型做不到什么（具体、有例子）
- 走过的弯路：哪些实验白跑了、为什么
- 如果重来会怎么改
- 如果有 10 倍算力先做什么

### 11. 复现指南
- 环境、命令、数据下载脚本
- 每个阶段的预期耗时与成本
- 已知的坑

### 附录
- 完整超参 yaml
- 生成样本
- 数据样本
- 环境版本清单（torch / cuda / flash-attn / harness 的精确版本）

## 写作要点

1. **每个数字都要能追溯到脚本或日志**。写不出来源的数字就删掉。
2. **失败的实验也要写**。只报成功的结果是论文腔，不是工程记录。
3. **不粉饰**。分数低就说低，并分析原因。500M 就是不如 7B，这不丢人。
4. **图比表好，表比文字好**。loss 曲线、缩放律拟合、能力增长曲线三张图撑起整份报告。
5. **先写第 10 节（局限与失败）**。趁记忆还新，训练过程中就随手往里记。等到最后补，细节全忘了。

## 训练期间的记录习惯

在 `reports/journal.md` 里逐日记：

```markdown
## D22 · 正式预训练 Day 1
- 09:00 8×H100 开机，环境验证通过，MFU 41%
- 11:30 step 8400 出现 loss spike（2.94 → 3.71），grad_norm 提前 200 步开始爬
- 11:45 回滚到 step 8000，跳过 200 batch，LR 降到 5e-4，恢复正常
- 猜测：某个 shard 里有大量重复的 base64 内容，待查
- 18:00 step 21000，val loss 2.83，中文 loss 明显高于英文（3.41 vs 2.61）
```

这份日志是报告第 5、10 节的原始素材。**没有它，训完就再也想不起来发生过什么。**
